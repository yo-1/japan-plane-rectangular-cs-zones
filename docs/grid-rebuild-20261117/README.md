# 座標桁の統一（2026-11-17、v2026.3）

元データ（国土数値情報 行政区域データ 2026年版）は、形式の中で小数9桁の座標とフル精度の座標が混在していました。そのまま統合した v2026.2 のポリゴンでは、9桁に一致しない頂点が残っていました。v2026.3 は、源泉を小数9桁のグリッドに揃えてから全レイヤーを作り直した版です。

## 作り方

1. 源泉の正規化： 行政区域データ 2026年版（GeoJSON、全47都道府県・125,130フィーチャ）の全頂点を小数9桁グリッドに揃えた（shapely set_precision、valid_output）。この正規化済み源泉は、森林計画区データの再構築（japan-forest-planning-zones v0.7）と共通です。
2. 市区町村×系の再統合： 断片を市区町村コードと系番号で統合（1,911地物）。系番号は `data/municipality_zones.csv` の対応で付け、系をまたぐ5市町村（小笠原村・薩摩川内市・南さつま市・三島村・十島村）は断片ごとに系を判定しました。属性は v2026.2 からそのまま引き継ぎました。
3. 都道府県（単位×系、392地物）と系（19地物）は、市区町村の地物から再統合しました。
4. スタイル（layer_styles）は v2026.2 の GeoPackage から引き継ぎました。

工程スクリプトは `scripts/rebuild_from_normalized.py`（作成）と `scripts/verify_rebuild.py`（検証）です。

## 検証結果（v2026.2 との全数つき合わせ）

桁の数え方： 頂点の座標が `round(座標, 9)` と一致しないものを「9桁に一致しない」と数えました。

|---|---|---|---|---|---|
| 市区町村 | 1,911 | 7.237% → 0.000% | 完全一致 | 0.010 ㎡ | 1.040 ㎡ |
| 都道府県 | 392 | 8.578% → 0.000% | 完全一致 | 0.010 ㎡ | 0.884 ㎡ |
| 系 | 19 | 9.432% → 0.000% | 完全一致 | 0.015 ㎡ | 0.843 ㎡ |

- 無効形状は全レイヤーで0、系どうしの重なりは0でした。
